## ⚡ Instalar (Windows) em 3 passos

1. 📥 Baixe em **[Releases](https://github.com/AbreuApps/fm27-estadios-release/releases/latest)**:
   - **Nunca usou mod?** → `FM27-Estadios-BR-Completo-1.0.0.zip` (já traz o BepInEx)
   - **Já tem BepInEx?** → `FM27-Estadios-BR-1.0.0.zip`
2. 📂 Descompacte e **feche o jogo**.
3. 🖱️ Dois cliques em **`instalar.bat`**. Ele acha o jogo sozinho. ✅

Depois, no jogo: **Preferências → Idioma → Português (Brasil)**.
⏳ A 1ª abertura com o BepInEx demora alguns minutos: **não feche**.
💾 Faça backup dos saves antes (`Documentos/Sports Interactive/Football Manager 27/games`).

## 🐧 Linux ou instalação manual

- Copie a pasta **`TaoMods`** para `BepInEx/plugins/` (na pasta do jogo).
- Copie `TaoMods/languages/portuguese_br.ltc` para `Documentos/Sports Interactive/Football Manager 27/languages/`.
- Linux (Steam → Propriedades → Opções de inicialização): `WINEDLLOVERRIDES="winhttp=n,b" %command%`

Passo a passo completo e problemas comuns: **[INSTALAR.md](INSTALAR.md)**.
